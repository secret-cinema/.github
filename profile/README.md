# Masters of immersive.

We exist to make people feel like they're part of something bigger.

We create moments of collective awe through theatrical experiences, because feeling part of something bigger strengthens communities.

*We’ve changed what audiences want from live events.*

*We’ve trained an industry to be more immersive.*

Giving people the chance to participate in their favourite stories, alongside friends and strangers alike, heightens emotions and unifies a group. Sociologists call it *‘collective effervescence’*. We call it an **_unforgettable night out._**
